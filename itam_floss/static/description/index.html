ITAMFloss

IT asset operations in one focused Odoo 18 app

Manage IT assets, assignments, inventory, maintenance, software licenses, reports, and audit history from one responsive interface backed by the Odoo ORM and PostgreSQL. Employees and departments come directly from Odoo Employees.

Designed for Arabic and English teams

The interface follows each user's Odoo language automatically, including native right-to-left Arabic and left-to-right English.

Included capabilities

  • Asset lifecycle, assignment, return, archive, and history
  • Inventory quantities and movement history
  • Preventive and corrective maintenance records
  • PC components and printer toner installation workflows
  • Software license seats and assignments
  • Native integration with Odoo employees, departments, and users
  • CSV import/export, reports, images, and JSON backup
  • Authenticated Odoo sessions and protected mutation endpoints
  • Complete activity history for operational traceability

Ready for Odoo.sh and on-premise

The app includes its compiled frontend and requires no Node.js on the Odoo server. It supports Odoo 18 Community and Enterprise and does not require Supabase or an external database service.

Native HR data and optional demo records

Production databases install without sample business records. Odoo demonstration databases can load the included sample branch, departments, and employees. Access in this release is restricted to Odoo administrators; dedicated ITAM roles can be introduced in a later version.
