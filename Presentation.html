خيارات النشر: مرونة كاملة عبر Odoo.sh أو محلياً

نشر Odoo.sh السحابي

Cloud Git Pipeline
  • 1. وضع مجلد الموديول itam_floss في مستودع Git.
  • 2. رفع الفرع (Git Push) لمشروع Odoo.sh ليتم البناء تلقائياً.
  • 3. تحديث قائمة التطبيقات في قاعدة البيانات المستهدفة.
  • 4. تفعيل موديول ITAMFloss بنقرة واحدة والبدء مباشرة.

نشر الاستضافة المحلية (On-Premise)

Custom Addons
  • 1. نسخ مجلد itam_floss إلى مسار الـ custom addons.
  • 2. التحقق من إدراج المسار في إعدادات addons_path.
  • 3. إعادة تشغيل خدمة Odoo وتحديث قائمة التطبيقات.
  • 4. تثبيت الموديول، حيث الأصول مدمجة مسبقاً ولا يلزم Node.js.
