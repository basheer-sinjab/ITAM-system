# نظام إدارة الطابعات — تشغيل محلي

يعمل المشروع محليًا بالكامل، دون Lovable أو Supabase أو تسجيل دخول.

## التشغيل

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في الطرفية. التطبيق يفتح مباشرةً دون حسابات أو كلمات مرور.

## البيانات

تُحفظ الطابعات، الأحبار، السجلات، الإعدادات والصور على نفس الجهاز داخل قاعدة المتصفح المحلية IndexedDB باسم `printers-manager-local`. لا تُرسل البيانات إلى أي خدمة خارجية.

لا تستخدم وضع التصفح الخاص، ولا تمسح بيانات الموقع من المتصفح إذا أردت الاحتفاظ بالبيانات.
